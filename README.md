# 🎮 Soku Advisor — 東方非想天則 リプレイ解析ツール

東方非想天則（th123）の対戦動画・リプレイファイル・リアルタイム入力記録を解析し、
プレイヤー向けのアドバイスを HTML レポートとして出力するツールです。

**ダウンロード:** [Releases](https://github.com/ankakepizza551/soku-advisor/releases) から `SokuAdvisor_vX.Y.zip` を取得し、展開して `SokuAdvisor.exe` を起動します。使い方は同梱の `readme.txt` にもあります。

---

## 🌟 主な機能

| 機能 | 説明 |
|---|---|
| HP 推移グラフ | 動画またはライブ記録から両プレイヤーの HP 変化をグラフ化 |
| ラウンド自動検出 | HP の上昇・下降パターンからラウンド境界を自動検出 |
| 入力分析 | ボタン使用率・移動方向・コマンド入力回数を可視化 |
| **P1 vs P2 比較** | 両プレイヤーの入力をサイドバイサイドで比較 |
| **ダメージイベント分析** | 被弾タイミングと直前の行動パターンを検出（動画だけの時は時刻と大きさのみ） |
| **相手の名前を伏せる** | ファイル名から読んだ相手の名前を「相手」と表示（既定でオン。CLI は `--show-opp-name` で表示）。AI に送る内容には常に入れない |
| **被弾の内訳** | 相手の始動技ごとに、自分が何をしている時に食らったかを表で表示（当てた技も同様） |
| **通算の内訳** | 被弾の記録を試合ごとに履歴へ貯め、同じキャラの組み合わせの通算で被弾の内訳を表示（プレイヤー名を入れた時） |
| **ガードの内訳** | 正ガード・誤ガード・空中ガード・ガードクラッシュの回数と、誤ガードになった相手の技 |
| **カード** | 両者のデッキ構成と、使ったスペルカード・スキルカード・システムカードの回数（使用回数はライブ記録のみ。`.rep` からはデッキ構成だけ） |
| **霊力分析** | 平均霊力・1玉未満の時間・ガードで削られた回数（ライブ記録のみ） |
| **キャラ別アドバイス** | 現在は無効（`char_data.json` の内容を精査中。`char_advisor.py` の `CHAR_ADVICE_ENABLED` で切替） |
| **AI自然文コーチング** | OpenAI 互換 API で解析結果を自然文解説（任意） |
| アドバイス生成 | 上記データをもとに日本語でアドバイスを自動生成 |

## 📁 ファイル構成

```
soku_advisor/
├── SokuAdvisor.exe        # スタンドアロン実行ファイル（Python 不要）
├── soku_advisor_app.py    # GUI アプリ本体（Tkinter）
├── analyzer.py            # 解析ロジック（動画・rep・ライブ JSON）
├── char_advisor.py        # キャラ別アドバイス生成
├── char_data.json         # 全20キャラの tips / 相手への注意点
├── card_data.json         # カード番号 → カード名（システムカードと全20キャラ）
├── ai_advisor.py          # LLM 自然文コーチング（OpenAI 互換 API）
├── soku_live_reader.py    # ゲームプロセスからリアルタイム入力記録
├── build_exe.ps1          # PyInstaller ビルドスクリプト
└── dist/
    └── SokuAdvisor.exe
```

## 🚀 使い方

### GUI（推奨）

`SokuAdvisor.exe` をダブルクリックして起動します。Python は不要です。

**基本的な流れ:**

1. 天則を起動しておく
2. SokuAdvisor を起動 → 「ゲーム接続済み」になるのを確認
3. 対戦前に **[記録開始]** をクリック
4. 対戦終了後に **[記録停止]** をクリック → `recording_xxx.json` が保存される
5. 動画ファイル（.mp4）と記録 JSON を選択
6. **P1/P2 キャラ**（任意）— ファイル名から自動推定できない場合に指定
7. **AI自然文コーチング**（任意）— `SOKU_AI_API_KEY` 設定時のみ有効
8. **[レポート生成]** をクリック → ブラウザで HTML が開く

**キャラ自動推定:** 動画・JSON のファイル名が `1830_PlayerA(aya) vs PlayerB(yuyuko)` 形式なら括弧内から自動取得します。

**AI コーチング設定（任意）:**
```powershell
# OpenAI
$env:SOKU_AI_API_KEY = "sk-..."
$env:SOKU_AI_MODEL = "gpt-4o-mini"   # 省略可

# ローカル Ollama
$env:SOKU_AI_API_KEY = "ollama"
$env:SOKU_AI_BASE_URL = "http://localhost:11434/v1"
$env:SOKU_AI_MODEL = "llama3.2"
```
環境変数を設定してから SokuAdvisor を起動すると、GUI の AI チェックボックスが有効になります。

---

### コマンドライン

```powershell
# 動画 + ライブ記録 JSON を使った解析（最も詳細）
python analyzer.py match.mp4 --live recording.json

# 動画のみ（HP グラフ + ラウンド結果 + 被弾の時刻と大きさ）
python analyzer.py match.mp4

# 動画 + .rep ファイル（入力の解析に加え、時刻を合わせて被弾直前の入力も推定）
python analyzer.py match.mp4 match.rep

# ライブ記録のみ（動画なし）
python analyzer.py --live recording.json

# 出力先を指定
python analyzer.py match.mp4 --live recording.json -o output.html

# キャラ指定 + AI コーチング（P2視点・文 vs 幽々子）
python analyzer.py match.mp4 --live recording.json --viewpoint 2 --p2-char aya --p1-char yuyuko --ai
```

## 📊 レポートの内容

### HP 推移グラフ
時系列で両プレイヤーの HP を折れ線グラフ表示。ラウンドの流れが一目でわかります。

### ラウンド結果
各ラウンドの勝敗・経過時間・最終 HP を表示します。

### アドバイス（例）
```
ラウンド結果: 1勝2敗
⚠️ PlayerA は 12 回被弾しました（コンボは1回として集計。平均 8% / 回、合計 96%）
  被弾12回のうち、霊力1玉未満の時に食らったのは2回
  ダメージを受けた直前の行動: 「打撃中」(5回)、「ダッシュ・飛翔中」(4回)
  相手の始動技ごとの被ダメージ: 打撃(306) 52%・4回、射撃(411) 20%・3回
  大ダメージ: 102.3秒（1:42） / 15%被弾（6ヒット） / 直前→打撃中 / 相手→打撃(306)
🎮 入力発生率 38.0% / ボタン押下率: A 10.5% / B 0.3% / C 1.2% / D 18.3%
🔷 霊力: 平均 4.2玉 / 1玉未満の時間 1.2% / ガードで削られた回数 1回
🎯 行動内訳: 打撃×58、射撃×11、スキル×10、ダッシュ・飛翔×87、ガード×6
📊 PlayerB の入力発生率 72.0% / ボタン押下率: A 7.7% / B 4.5% / C 2.6% / D 0.1%
```

### P1 vs P2 入力比較
- ボタン使用率（A/B/C/D）の並列バーグラフ
- 入力発生率・前進率・後退率の比較
- 特殊コマンド（236/214/623 など）の使用回数対比

## ⚙️ 技術仕様

### 動作環境
- Windows 10/11 x64
- 天則（th123）が起動している必要があります（ライブ記録時）

### 管理者権限について
天則を **管理者として実行** している場合、SokuAdvisor も同じく管理者権限が必要です。
（天則側が管理者プロセスだと、通常権限のツールからメモリ読み取りが拒否されます）

**推奨手順（天則を管理者起動する場合）:**
1. 天則を管理者として起動
2. SokuAdvisor を起動
3. ステータスが「権限不足」と表示されたら **[管理者として再起動]** をクリック
4. UAC で許可 → 再起動後に「天則接続中」になる

GUI 上部には「本ツール: 通常権限 / 管理者権限」も表示されます。
常に管理者で使う場合は、ショートカットのプロパティから「管理者として実行」を有効にしても構いません。

### 対応ファイル形式
| 形式 | 説明 |
|---|---|
| `.mp4` | 録画動画。HP バーを画像認識で解析（640×480 基準） |
| `.rep` | 天則のリプレイファイル。対人戦（ネット対戦を含む）は両プレイヤー、対CPU戦は P1 のボタン・方向入力が入っています |
| `.json` | `soku_live_reader.py` が出力するライブ記録。両プレイヤーの入力・コマンド・HP を含む |

### ライブ記録の仕組み
ゲームプロセス（`th123.exe`）のメモリを直接読み取り、フレームごとに以下を記録します：
- 両プレイヤーの HP
- 方向入力（↑↓←→）
- ボタン入力（A/B/C/D）
- コマンド入力コード（236/214/623/421/22）
- 手札のカード（毎フレーム）と、試合開始時のデッキ（試合ごとに1回）
- 本体に出ている攻撃判定の数（出がかり・打ち合い負け・空振り後の区別に使う）

### HP バー検出（動画解析時）
- 解像度: 640×480 固定
- P1 バー: x=[10, 261]、y=39
- P2 バー: x=[378, 629]、y=39
- HP 色判定: R > 180、G > 80、B < 160

## ⚠️ 注意事項

- **.rep ファイルについて**: 入っているのはボタン・方向の入力だけです（対CPU戦は P1 のみ）。HP・行動回数・被弾の分析には **ライブ記録** が必要です。
- **ライブ記録**: `th123.exe` のプロセスメモリを読み取ります。天則を管理者起動している場合は SokuAdvisor も管理者権限が必要です。
- **セキュリティソフト**: メモリ読み取りをブロックする場合があります。
- **動画 + .rep の被弾直前の入力**: .rep には時刻が無いため、攻撃ボタンと相手の HP の減りが重なる位置を探して動画に合わせています（ずれは 0.3 秒程度まで）。押したボタンからの推定で、技の種類までは分かりません。合わせられなかった時は出しません。
- **動画 + ライブ記録の再生位置**: 動画とライブ記録は開始位置が違うので、両方の HP の減り方をラウンドごとに突き合わせて、大ダメージの時刻を動画の再生位置（「動画 1:23」）で出します。.rep を後から再生して録った動画でも構いません。動画に写っていないラウンドや、合わせられなかった時はライブ記録の時刻のまま出します。
- **レポートから動画へ飛ぶ**: 動画を渡すとレポートの上に動画が入り、点線の付いた時刻（大ダメージ・各ラウンドの頭）や HP グラフをクリックすると、その場面の 2 秒手前から再生します。レポートは動画への相対パスを持つので、動画と同じフォルダに置いたまま開いてください。
- **技名**: 通常技は「JA」「6C」のような名前で、スキルはその記録で実際に入力されたコマンド（「236B」など）で出します。確かめられていない番号は「打撃(330)」「スキル(570)」のようにカテゴリと番号のままです。
- **位置の分析**: ライブ記録にキャラの位置と向きが入っている時（記録 version 4 以降）だけ、画面端に追い込まれていた時間、相手との距離の内訳、被弾した時の距離と画面端かどうかを出します。それより前の記録では出ません。
- **HP 検出精度**: 動画の録画設定や解像度によっては HP バーの検出精度が低下する場合があります。
