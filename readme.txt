================================================================================
  Soku Advisor - 東方非想天則 対戦解析ツール  v1.6
================================================================================

対戦の録画（MP4）やライブ記録から、HP の推移・被弾の内訳・入力傾向を
HTML レポートとして出力するツールです。

  対象ゲーム : 東方非想天則（th123）v1.10a 想定
  動作環境   : Windows 10 / 11（64bit）
  必要なもの : Python などの追加インストールは不要（SokuAdvisor.exe のみ）


================================================================================
  同梱ファイル
================================================================================

  SokuAdvisor.exe  … 本体（これを起動します）
  readme.txt       … この説明書


================================================================================
  できること
================================================================================

  [ライブ記録を使った場合（推奨）]
    - HP の推移グラフ、ラウンドごとの勝敗
    - 被弾の内訳
        ・被弾した時刻と大きさ、直前に何をしていたか
          （起き上がり直後・ガードクラッシュ中も区別します）
        ・相手のどの技から食らったか（始動技ごとの被ダメージ）
        ・被弾した時の相手との距離、画面端だったかどうか
    - 自分のどの技が通っているか（始動技ごとの与ダメージ）
    - 画面端に追い込まれていた時間、相手との距離の内訳
    - 霊力（平均、1玉未満の時間、ガードで削られた回数）
    - 行動の回数（打撃・射撃・スキル・ダッシュ飛翔・ガード）と相手との比較
    - 両者のデッキ構成と、使ったカードの回数
      （スペルカード・スキルカード・システムカードをカード名で出します）
    - 連戦の場合は、連戦全体での始動技の集計と試合ごとの推移
    - AI による自然文コーチング（任意・APIキー設定時）
    - プレイヤー履歴の蓄積と傾向分析

  [ライブ記録 + 動画（MP4）の場合]
    上に加えて、
    - レポートの上に動画が入り、大ダメージの時刻・各ラウンドの頭・HP グラフを
      クリックすると、その場面の 2 秒手前から再生します
    - 動画とライブ記録は別々に撮ったもので構いません（.rep を後から再生して
      録画した動画でも大丈夫です）。HP の減り方を突き合わせて時刻を合わせます

  [動画（MP4）だけの場合]
    - HP の推移グラフ、ラウンドごとの勝敗
    - 被弾した時刻と大きさ（クリックでその場面へ）
    ※ 入力・行動・位置の分析はできません

  [動画 + .rep の場合]
    - ボタン・方向の入力の集計
    - 被弾直前に押していたボタンの推定
    - 両者のデッキ構成（カードの使用回数は出ません）
    ※ .rep に入っているのは入力だけです。対人戦は両プレイヤー、
       対 CPU 戦は P1 の入力のみです。
       HP・行動・位置の分析にはライブ記録が必要です


================================================================================
  基本的な使い方（ライブ記録 + 動画）
================================================================================

  ① 天則（th123）を起動する

  ② SokuAdvisor.exe をダブルクリックで起動する

  ③ 画面上部の「ゲーム状態」を確認する
        「天則接続中」 … OK
        「天則未起動」 … 天則が起動していない
        「権限不足」   … 下記「管理者権限について」を参照

  ④ 対戦が始まる前に [記録開始] を押す
        連戦する場合も、止めずにこのまま続けて OK です
        （試合ごとに自動で区切られます）
        保存先を指定しなければ、ビデオ フォルダに JSON が自動保存されます
        ※ リプレイの再生中でも記録できます

  ⑤ 対戦が終わったら [記録停止] を押す
        停止後に「ファイル名の変更」ダイアログが表示されます。
        対戦相手やキャラが分かる名前をつけておくと管理しやすくなります。
        変更しない場合はそのままキャンセルまたは OK を押してください。

  ⑥ 「レポート生成」で以下を指定する
        動画       … 対戦の MP4（任意。あるとレポートから場面へ飛べます）
        ライブ記録 … ⑤で保存した JSON ファイル
        解説視点   … 自分が P1（左）か P2（右）かを選択
        P1/P2キャラ … 任意。通常は「（自動）」のままで構いません
                      （ライブ記録にキャラが入っています）
        プレイヤー名 … 任意。入力すると履歴が蓄積されます
        AI自然文   … 任意。環境変数 SOKU_AI_API_KEY を設定している場合のみ
        過去履歴参照 … プレイヤー名を入力した場合に有効。デフォルト ON

  ⑦ [レポート生成] を押す
        完了するとブラウザで HTML レポートが開きます
        レポートは動画と同じフォルダに保存されます。動画へ飛ぶ機能を使う時は、
        レポートと動画を同じフォルダに置いたまま開いてください


================================================================================
  管理者権限について（重要）
================================================================================

  天則を「管理者として実行」している場合、SokuAdvisor も管理者権限が
  必要です。権限が足りないと「権限不足」と表示され、記録できません。

  【手順】
    1. 天則を管理者として起動
    2. SokuAdvisor を起動
    3. 「権限不足」と出たら [管理者として再起動] をクリック
    4. Windows の UAC（ユーザーアカウント制御）で [はい] を選ぶ
    5. 再起動後、「天則接続中」になれば OK

  【毎回 UAC が面倒な場合】
    SokuAdvisor.exe のショートカットを右クリック
      → プロパティ → 詳細設定
      → 「管理者として実行」にチェック

  画面上部に「本ツール: 通常権限 / 管理者権限」と表示されます。
  天則と同じ権限レベルで揃えてください。


================================================================================
  動画（MP4）について
================================================================================

  - 天則の画面解像度 640x480 で録画した動画が最も精度が高いです
  - 4:3 であれば他の解像度も読めますが、精度が落ちることがあります
    4:3 でない動画（横長の枠付きなど）は読めません
  - 動画がなくても、ライブ記録 JSON だけでレポート生成は可能です


================================================================================
  レポートの読み方（補足）
================================================================================

  - 技名
      通常技は「JA」「6C」「DA」（ダッシュ A）のように出ます。
      スキルは、その試合で実際に入力されたコマンドから「236B」「J22B」
      （J は空中）のように出します。
      確かめられていない技は「スキル(570)」のように番号のまま出ます。

  - 距離
      相手との横の距離で 4 つに分けています。
        密着 … 60 未満 / 近距離 … 60〜220 / 中距離 … 220〜450 / 遠距離 … 450 以上
      開幕の距離は 320（中距離）です。

  - 画面端
      ステージの端から 150 以内にいて、相手が中央側にいる時を
      「画面端に追い込まれている」としています。

  - 位置・距離・画面端の分析は v1.5 以降で記録したライブ記録でだけ出ます。
    それより前の記録には位置が入っていません。

  - カード
      デッキ構成と使用回数は v1.6 以降で記録したライブ記録で出ます。
      連戦でキャラもデッキも同じ時は全試合の合計を、違う時は試合ごとに出します。
      それより前の記録には手札が入っていないため、スペルカードの使用回数だけ出ます。
      相手の符蝕薬で壊されたカードは、使った回数に数えません。
      スペルカードのコストとして消えたカードも、使った回数に数えません。
      ※ v1.6 で入ったばかりの機能で、ネット対戦での確認が十分ではありません。
         回数が実際と違う時は、下の「よくある質問」の手順で知らせてください。


================================================================================
  よくある質問
================================================================================

  Q. 記録開始を押してもフレーム数が増えない
  A. 天則が対戦画面（バトル中）になっているか確認してください。
     メニュー画面では記録されません。

  Q. 「天則未起動」のまま
  A. 天則 v1.10a が起動しているか確認してください。
     別バージョンの天則では接続できない場合があります。

  Q. セキュリティソフトにブロックされた / ダウンロード時に警告が出た
  A. ライブ記録はゲームのメモリを読み取ります（書き込みはしません）。
     ウイルスではありませんが、誤検知されることがあります。
     SokuAdvisor.exe を除外設定に追加してください。

  Q. レポートの時刻をクリックしても動画が再生されない
  A. レポートと動画が同じフォルダにあるか確認してください。
     レポートは動画の場所を覚えているので、どちらかを移動すると
     再生できなくなります。

  Q. 大ダメージの時刻に「動画」と付いていない
  A. ライブ記録と動画の時刻を合わせられなかった時です。
     別の試合の動画を指定していないか確認してください。

  Q. 記録を停止したら毎回ファイル名ダイアログが出る
  A. 仕様です。変更しない場合はそのままキャンセルまたは OK で閉じてください。
     ダイアログで名前を変更すると、レポート欄のパスも自動で更新されます。

  Q. プレイヤー履歴はどこに保存されるの？
  A. ユーザーフォルダ以下の Videos\.soku_advisor_history\ に
     プレイヤー名.json として保存されます。
     削除すれば履歴をリセットできます。最大 50 セッション分が保持されます。

  Q. カードの使用回数が実際と違う
  A. 不具合の可能性があります。次の 3 つを添えて、X（@ankakepizza551）まで知らせてください。
       ・その対戦のライブ記録（.json）
       ・どのカードが何回ずれているか（例: 霊撃札が 1 回多い）
       ・ネット対戦かどうか、SokuRoll などのロールバックを使っているか
     その対戦の .rep もあれば、原因を調べやすくなります。

  Q. AI自然文コーチングを使いたい
  A. 事前に環境変数を設定してから SokuAdvisor を起動してください。
     【OpenAI の例】
       SOKU_AI_API_KEY = sk-...（あなたの API キー）
       SOKU_AI_MODEL   = gpt-4o-mini（省略可）
     【ローカル Ollama の例】
       SOKU_AI_API_KEY  = ollama
       SOKU_AI_BASE_URL = http://localhost:11434/v1
       SOKU_AI_MODEL    = llama3.2 など
     設定後、レポート生成画面の「AI自然文コーチング」にチェックを入れます。
     API 利用料・通信はご自身の環境に依存します。
